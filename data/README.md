# data/ — データの置き場所

**このフォルダの中身は Git で追跡しない。** 実データは個人情報を含みうるので、Git にもクラウドにも写さない（外す仕組み → [`README.md`](../README.md)「構成」の `.gitignore`。止める仕組み → [`docs/CHECKS.md`](../docs/CHECKS.md) 1 節）。

| フォルダ | 中身 | 誰が書くか |
|---|---|---|
| `raw/` | 受け取ったままのデータ。**書き換えない**（再現の起点） | 人 |
| `raw/dummy/` | 列名・型・欠損の分布を本番に似せたダミー（下） | 人 |
| `interim/` | 途中のデータ（結合・型の変換など） | 解析のコード |
| `processed/` | 解析にそのまま使うデータ | 解析のコード |
| `external/` | 外から持ってきた参照用のデータ（地域統計・コード表など） | 人 |

**ダミーデータは自分で用意する**（テンプレートは作り方を持たない）。作った経路は `CHANGELOG.md` に書く。ダミーで出した成果物は、名前やフォルダで本番のものと見分けられるようにする。
